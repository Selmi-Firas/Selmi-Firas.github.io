SOC Lab — Security Onion


Designed and deployed a full enterprise Security Operations Center (SOC) environment on a Proxmox virtual machine running Security Onion 2 in standalone mode. The platform provides network security monitoring (NSM) and enterprise security monitoring (ESM) by integrating multiple detection engines into a single, unified console.

— Infrastructure Setup —

Security Onion was installed on a Proxmox VM configured with 400 GB disk, 2 CPU cores, and 20 GB RAM. A Windows Server 2016 machine served as the monitored target — configured with DHCP for automatic IP assignment, FTP for file transfer, DNS for name resolution, Active Directory for centralized user management, and IIS hosting a replica of the company's production website. The full network diagram placed Security Onion between the attacker machine and the Windows server to capture all traffic.

— Detection Engines Deployed —

Suricata — Primary NIDS engine. Monitors network traffic in real time using signature-based and behavioral rules. Generates alerts visible through the Scirius interface and Kibana dashboards.
Snort — Secondary IDS engine. Deployed alongside Suricata for comparative detection coverage and alert correlation.
Zeek (formerly Bro) — Network metadata engine. Generates structured logs capturing IP addresses, ports, protocols, session durations, and payload metadata — used for threat hunting and forensics.
Wazuh — Host-based IDS (HIDS). Agents deployed on both Linux and Windows endpoints, monitoring file system changes, authentication failures, and system log anomalies.
OSSEC — Supplementary HIDS for host log analysis and rootkit detection.

— SOC Console Components —

Kibana — Central visualization platform. Custom dashboards display real-time security events, traffic volumes, alert timelines, and system health across all monitored nodes.
Elasticsearch — Distributed indexing and storage engine powering fast search across all log data from all sources simultaneously.
Logstash — Log ingestion, transformation, and enrichment pipeline. Pre-processes events before indexing into Elasticsearch.
Grafana — Time-series monitoring dashboards for real-time system health, resource utilization, and network traffic metrics.
Cases Interface — Formal incident investigation workflow. Analysts create cases from alerts, assign severity, track status (new / in-progress / closed), attach observables (IP addresses), add comments, and maintain a full audit history.
Hunt — Proactive threat hunting using custom queries across all collected logs.
PCAP — Full packet capture storage for deep post-incident analysis using tcpdump and Zeek.
CyberChef — Data transformation and decoding tool integrated into the SOC for rapid forensic analysis.

— Attack Simulation & Validation —

A TCP XMAS FLOOD DDoS attack was launched using Pentmenu from a Kali Linux machine targeting the Windows Server. During the attack, incoming traffic on the target surged from a baseline of ~8 Kbit/s to nearly 100 Mbit/s — overwhelming both the Windows server and the test hardware. Suricata and Snort detected the anomalous traffic spike and generated real-time alerts within the SOC console. The full incident was escalated to a Case, with the attacker IP logged as an observable and the alert chain documented end-to-end.

— IPS Mode —

Security Onion's IPS mode was enabled using Suricata in inline configuration. Upon detecting the attack, Suricata automatically blocked the malicious traffic stream, demonstrating automated threat containment without manual intervention.

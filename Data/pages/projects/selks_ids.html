SELKS — IDS / IPS


Deployed a dual-layer intrusion detection and prevention system using SELKS for network intrusion detection (IDS) and Suricata on pfSense for active intrusion prevention (IPS) — providing layered security coverage for a live enterprise network.

— What is SELKS? —

SELKS is a Linux-based security platform developed by Stamus Networks, built around Suricata as its core detection engine. It integrates the full ELK Stack (Elasticsearch, Logstash, Kibana), Scirius for rule management, Arkime for pcap ingestion and visualization, and EveBox for additional alert dashboards. SELKS provides NSM (Network Security Monitoring) and ESM (Enterprise Security Monitoring) capabilities from a single, cohesive interface.

— IDS Deployment: SELKS on Proxmox —

SELKS was installed on a Proxmox VM (400 GB disk, 2 CPU cores, 10 GB RAM). The installation uses a unique method: after a standard OS install, a FirstTimeSetup file is executed from the desktop terminal — this script installs and configures all SELKS components automatically. SELKS sensors were positioned at the network perimeter, the DMZ boundary, and key server segments to capture all relevant traffic. The Scirius rule management interface was used to configure Suricata detection rules and monitor live alert feeds.

— SELKS Services Deployed —

IDS (Suricata) — Monitors all network traffic in real time, detecting port scans, DoS/DDoS attempts, protocol anomalies, and exploitation attempts against known vulnerabilities.
Network Metadata (Zeek-style logging) — Captures a complete record of all network communications: source/destination IPs, ports, protocols, session duration, and payload metadata — without storing full pcaps, offering scalable visibility.
Threat Hunting (Scirius) — Provides a management interface for Suricata rulesets and a threat hunting dashboard for querying historical event data.
Full Packet Capture (Arkime) — Ingests and stores raw pcap data, enabling complete packet-level replay and forensic investigation of past network sessions.
Alert Dashboards (EveBox + Kibana) — Real-time alert visualization, event timelines, and custom dashboard creation.

— IPS Deployment: Suricata on pfSense (VirtualBox) —

Because permission to test IPS on the live production network was not granted, a separate virtual network was built in VirtualBox to evaluate the IPS component without risk to the enterprise. Two VMs were created: one running pfSense as the gateway/firewall, and one running Ubuntu as the internal endpoint. Suricata was installed on pfSense via the Package Manager and configured in Legacy IPS mode — upon detecting a threat, it automatically adds pfSense firewall rules to block the malicious traffic source.

— Docker macVLAN Isolation —

To give pfSense/Suricata full visibility over container-to-container traffic (which is hidden from the firewall in the default Docker bridge network), a macVLAN Docker network was created. Unlike the standard docker0 bridge (which only shows external traffic to the firewall), macVLAN assigns each container a unique MAC address on the physical network segment — making all inter-container traffic visible to Suricata. A container named with a test identity was deployed at a static IP, and used as the attack target. Custom Suricata rules (ICMP filter rules) were written and applied to validate detection coverage.

— Attack Simulation & Detection —

A TCP XMAS FLOOD DDoS attack was launched from a Kali Linux machine using Pentmenu (option 2 → DoS → option 6 → TCP XMAS FLOOD). The attack targeted a Windows Server with a random source IP. Traffic on the target surged from ~8 Kbit/s baseline to nearly 100 Mbit/s. SELKS detected the surge within seconds — Scirius generated real-time alerts visible in both the EveBox and Kibana dashboards, showing the attacker IP, attack type, and affected protocols. On the pfSense/Suricata IPS side, the Legacy Mode automatically blocked the attacking source by injecting a firewall rule.

— Deployment Modes Evaluated —

On-Premises — Full control over data and infrastructure. SELKS installed directly on a physical or Proxmox VM server inside the enterprise network.
Cloud — Scalable deployment on AWS, Azure, or GCP. Lower upfront cost, managed underlying infrastructure.
Hybrid — SELKS on-premises for internal traffic; cloud deployment for analyzing external web traffic. Combines control and flexibility.

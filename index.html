~/projects/zero-trust DESIGNED & VALIDATED

Zero-Trust Network Architecture — IT/OT Segmentation

Designed the full architecture: topology, IP addressing scheme, and security zones for an enterprise network that had no segmentation, a flat IP space, and no firewall or IDS. The core decision: route IT and OT into separate Layer 3 networks, turning invisible switched traffic into routed flows a firewall can actually enforce. Deployed dual firewalls (pfSense for IT, Cyberoam for OT), an isolated DMZ, and built 802.1X/FreeRADIUS network access control myself. Directed a 7-person team on the identity and monitoring layers.

~/projects/sdn-control-plane MEASURED RESULT

SDN Control Plane for a Distributed Network (M.S. thesis)

A centralized SDN-style control plane managing a 17-node network of diffrent distances with full control-plane / data-plane separation: active telemetry benchmarks every node before it's assigned work, a watchdog raises graduated alerts on degraded links, paths are ranked and selected by measured quality, and an EDF scheduler orders operations against deadlines with closed-loop reliability feedback.

10,000 runs: 19.0% task success vs 12.4% state-blind baseline → +6.6 pts

Built in Python over a simulated quantum network (NetSquid), a substrate that made the monitoring and scheduling problem unusually demanding.

SDNPython telemetryscheduling closed-loop control
~/projects/can-llm-pipeline PROOF OF CONCEPT

Real-Time Sensor-to-LLM Pipeline over CAN Bus

An end-to-end embedded pipeline crossing four transport layers: a temperature/humidity sensor feeds an Arduino Uno, which frames readings onto a CAN bus (MCP2515 transceivers) to a Raspberry Pi 4 gateway; the Pi decodes the frames and forwards them over Ethernet to a Linux host running a local LLM (Ollama/DeepSeek) that returns context-aware advice in real time, cover the sensor with your hand and the output changes in seconds.

protocol chain: sensor → SPI → CAN → IP → local AI inference
